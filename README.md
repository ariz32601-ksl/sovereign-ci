# Sovereign-CI: Autonomous DevOps Self-Healing Agent

An intelligent, multi-step pipeline immune system mitigating high-performance ML framework optimization bottlenecks via automated context analysis, Model Context Protocol (MCP) tool routing, and branch isolation.

## 🚀 System Architecture Spec
- **Cognitive Core:** Gemini 2.5 Pro Neural Processing via Unified Google GenAI SDK
- **Tool Binding:** Model Context Protocol (MCP) Integration
- **Execution Engine:** Local Python-based Git Tool Server (`mcp-server-git`)
- **Remediation Layer:** Regex-purified AST file injection with automated branch isolation
- **Deployment Vector:** Multi-cloud automation via headless GitLab CI/CD Cloud Runners

## 💻 Local Onboarding & Replication Protocol
```bash
# Clone the repository
git clone https://github.com
cd sovereign-ci

# Bind the secure Gemini endpoint token
export GEMINI_API_KEY="your-google-studio-api-key-here"

# Ignite the automated diagnostic engine loop
python3 src/sovereign_core/brain.py
```
